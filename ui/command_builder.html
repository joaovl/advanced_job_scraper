Scraping Options

  • --linkedin-only - Only run LinkedIn scraper (fastest)
  • --workday-only - Only run Workday scrapers (39+ companies)
  • --playwright-only - Only run Playwright (Google, Apple, etc.)
  • --skip-linkedin - Run all except LinkedIn
  • --export-only - Generate exports from existing data
  • -t 24h - Jobs from last 24 hours
  • -g 101165590 - UK-wide search

Analysis Options

  • -i file.json - Specify input file (default: latest)
  • --cv path - Path to CV file (default: data/cv.txt)
  • -b ollama - Use Ollama backend
  • -m haiku - Use Haiku model (faster)
  • --min-score 8 - Higher threshold for matches
  • -n 50 - Limit to 50 jobs (for testing)
  • -s - Sequential mode (no parallel)

Output Files

  • output/linkedin_jobs_*.json - LinkedIn scraper results
  • output/master_jobs_*.json - Combined all scrapers
  • output/all_jobs_*.xlsx - Excel export
  • output/analysis_*.json - AI analysis results
  • output/analysis_*.xlsx - Analysis Excel report
  • output/analysis_*_shortlist.json - Matched jobs only

Config Structure

  • cv_file - Path to your CV
  • scraping.location - Default location
  • scraping.geo_id - LinkedIn geoId
  • scraping.time_range - Default time filter
  • scraping.job_titles - Job titles to search
  • analysis.backend - claude or ollama
  • analysis.model - AI model to use
  • filters.exclude_in_title - Title blacklist
  • filters.positive_keywords - Score boosters
